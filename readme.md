# Deep Learning Practicals

## About this Notebook
This notebook contains practical exercises on image processing and Convolutional Neural Networks (CNNs). It uses the CIFAR-10 image dataset and demonstrates preprocessing, convolution, pooling, model training, data augmentation, and transfer learning.

## Requirements
Install the following Python libraries before running the notebook:

```bash
pip install numpy matplotlib tensorflow
```

## How to Run
1. Open `PR_4_reorganized.ipynb` in Jupyter Notebook or VS Code.
2. Make sure Python and the required libraries are installed.
3. Run the cells from top to bottom.
4. The CIFAR-10 dataset may download automatically the first time it is loaded.
5. Check the printed results, plots, image displays, and model summaries after running the cells.

## Practicals and Tasks

### Practical 1: CIFAR-10 Dataset and Image Preprocessing
- Loading and exploring the CIFAR-10 dataset.
- Understanding image dimensions and pixel values.
- Normalizing image data.
- Encoding image labels.

### Practical 2: Convolution, Padding, Stride and Feature Maps
- Understanding convolution operations.
- Working with kernels and filters.
- Understanding padding and stride.
- Visualizing feature maps.

### Practical 3: Pooling Layers and CNN Architectures
- Understanding pooling layers.
- Comparing max pooling and average pooling.
- Learning about CNN architectures, including LeNet-5.

### Practical 4: CNN Training and Backpropagation
- Building and training a CNN model.
- Understanding model parameters and backpropagation.
- Monitoring training and validation performance.
- Using early stopping and learning-rate reduction.

### Practical 5: Data Augmentation
- Understanding data augmentation.
- Applying transformations to training images.
- Improving model generalization.

### Practical 6: Transfer Learning
- Understanding transfer learning.
- Using a pretrained model.
- Fine-tuning a model for image classification.
- Comparing training and validation results.

## Main Topics Covered
- CIFAR-10 dataset
- Image preprocessing and normalization
- One-hot encoding
- Convolution and feature maps
